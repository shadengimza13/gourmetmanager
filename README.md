GOURMETMANAGER

Prototype statique responsive de gestion de recettes.

Le projet permet :

- d'afficher une liste de recettes ;
- d'afficher le titre et la catégorie ;
- d'afficher ou masquer le détail d'une recette ;
- d'ajouter dynamiquement des ingrédients ;
- d'ajouter une nouvelle recette ;
- d'utiliser l'interface sur ordinateur et mobile.

Structure du projet :

index.html
assets/style.css
Model/RecipeModel.js
View/RecipeView.js
Controller/RecipeController.js

Le projet utilise HTML, CSS et JavaScript.

La structure Model / View / Controller permet de séparer les données, l'affichage et la logique de l'application.
